# College Event Management System

## 1. Project Title

**College Event Management System**

## 2. Business Goal

The goal of the College Event Management System is to provide a centralized platform for managing college events.

The system will allow students to view upcoming events, register for events, receive event information, and track their registrations. Administrators and event coordinators can create events, manage registrations, update event details, and monitor participation.

The main objectives are:

* Reduce manual event registration work.
* Provide students with easy access to college events.
* Manage event registrations efficiently.
* Maintain event and participant information.
* Improve communication between students and event organizers.

## 3. Epics

### Epic 1: User Management

Manage student and administrator accounts.

### Epic 2: Event Management

Allow administrators and coordinators to create and manage college events.

### Epic 3: Event Registration

Allow students to browse events and register for them.

### Epic 4: Notifications

Provide students with important event updates and reminders.

### Epic 5: Event Reports

Allow administrators to view registration and participation reports.

## 4. User Stories

### Epic 1: User Management

**US-01:**
As a student, I want to create an account so that I can register for college events.

**US-02:**
As a student, I want to log in securely so that I can access my account.

**US-03:**
As an administrator, I want to manage user accounts so that I can control system access.

### Epic 2: Event Management

**US-04:**
As an event coordinator, I want to create an event so that students can view and register for it.

**US-05:**
As an event coordinator, I want to update event details so that students receive accurate information.

**US-06:**
As an event coordinator, I want to delete an event so that cancelled events are removed from the system.

### Epic 3: Event Registration

**US-07:**
As a student, I want to view available events so that I can choose an event to attend.

**US-08:**
As a student, I want to register for an event so that I can participate in it.

**US-09:**
As a student, I want to cancel my registration so that my place can be given to another student.

### Epic 4: Notifications

**US-10:**
As a student, I want to receive event notifications so that I don't miss important updates.

**US-11:**
As an event coordinator, I want to send event updates so that registered students are informed about changes.

### Epic 5: Event Reports

**US-12:**
As an administrator, I want to view the number of registrations so that I can monitor event participation.

**US-13:**
As an administrator, I want to generate event reports so that I can analyze event participation.
